# andreggmartines.github.io

Site pessoal de [André Martines](https://www.linkedin.com/in/andreggmartines/), QA Engineer.

Página estática em HTML, CSS e JavaScript, sem framework. O próprio site tem testes em Cypress (`cypress/e2e/site.cy.js`): apresentação, laboratório interativo, links dos projetos e download do currículo.

```bash
npm install
npm run serve   # http://localhost:4500
npm test
```

## Projetos

- [checkout-qa-portfolio](https://github.com/andreggmartines/checkout-qa-portfolio): Cypress, Postman/Newman e SQL
- [playwright-qa-portfolio](https://github.com/andreggmartines/playwright-qa-portfolio): Playwright e TypeScript
- [banco-digital-cypress-qa](https://github.com/andreggmartines/banco-digital-cypress-qa): Cypress, API e acessibilidade
